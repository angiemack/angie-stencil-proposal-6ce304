
**Colors:**
- Page background (bg): #FBF6F4 (cream) — used for the entire page, edge to edge, no exceptions
- Surface: #FFFFFF — used only for the offer card
- Text (all): #3B3B3B (charcoal) — no pure black anywhere
- Accent / dusty rose: #F4B69A — used only for pull-quote left border and link underline
- Aside border: #B9C8B1 (sage) — used only for the aside left border
- No other colors on the page

**Fonts:**
- Display / serif: Cormorant Garamond (Google Fonts) — used for headline, salutation, pull quote, transition lines, evidence numbers and labels, numbered list numbers, signature, offer card headings. Always light weight where available.
- Body: Public Sans (Google Fonts), light weight — used for body paragraphs, captions, list text, aside text, kicker, small labels
- Never swap these two fonts for any other typeface

**Layout:**
- Single centered column, max-width ~680px, horizontally centered on the page
- Top padding ~140px, roughly 96px between major beats
- Completely flat — zero border radius on everything, zero box shadows anywhere
- Sharp corners universally

**Signature moment:** The pull-quote's 2px dusty-rose left border (#F4B69A) — the only color accent on an otherwise monochrome page, making it feel like a highlighted passage in a personal letter.

**Copy voice:** Intimate and assured — the tone of someone writing to an equal, not pitching to a superior. Warm without being effusive; specific without being transactional.
